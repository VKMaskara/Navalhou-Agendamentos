# 💈 Navalhou

---

## Sobre o projeto

O Navalhou é o meu primeiro projeto Full Stack voltado para o meu desenvolvimento profissional. Consiste em um sistema SaaS para gerenciamento de barbearias, desenvolvido como projeto de portfólio para demonstrar conhecimentos em desenvolvimento Full Stack, arquitetura de software e boas práticas de engenharia.

---

## Objetivos

Construir uma aplicação completa, desde o levantamento de requisitos até o deploy, simulando o desenvolvimento de um projeto em um ambiente profissional.
